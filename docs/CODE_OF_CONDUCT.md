# Code of conduct

Be decent to people.

Disagree about the code as much as you like — this project is built on recorded
disagreements, and a well-argued objection is worth more than agreement. Attack
the design, never the person holding it.

Not acceptable: harassment, personal attacks, discriminatory language,
publishing someone's private information.

## Reporting

Report a problem to gabin.capelle.pro@gmail.com. Reports stay private.

This is a small project maintained by one person, who will read what you send
and act on it. Consequences range from a request to stop through to a ban,
depending on what happened.
